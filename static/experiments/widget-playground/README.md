# Автономный образец виджета · v2, 17.10.2026

Откройте index.html через локальный статический сервер либо переносимый artgents-widget-playground-v2.html в браузере. HTML содержит шрифты, картинки, CSS, JS и данные. Работает без подключения к боту и без VPS.

## Что внутри

Восемь услуг / шестнадцать предложений из текущих клиентских пакетов: классическая имплантация (Implantium, Impro, Nobel), All-on-4 НикаДент, приём ЛОРа, биоревитализация, отбеливание, скрининг шейки матки, лазерная эпиляция и ботулинотерапия. Полные составы, исключения, условия, этапы оплаты и коммерческие тексты экспортируются без пересказа. Карточки отображает копия настоящего price_card.js. Дата снимка — 17.10.2026.

Каталог: направление → услуга → предложение → полная карточка. Вкладки сохраняют текущий экран и разговор. В диалоге есть кнопки продолжения, варианты цен и полные карточки. Ответы на произвольный ввод подготовленные: это проверка интерфейса, без подключения модели.

Форма использует разметку и обработчики полей настоящего booking_form.js. Во вкладке «Запись» она расширенная, внутри карточки и диалога — компактная. Только загрузка определения и отправка заменены локальным результатом. Имя, телефон и согласие обязательны; контакты остаются в памяти страницы. После обновления страницы форма снова пустая. Сетевых запросов и сохранения контактов нет.

## Оформление

Вверху только Inter / Roboto. Ползунков, меню настроек и сохранённых старых настроек больше нет. CSS-переменные находятся в :root файла styles.css, их можно менять через F12. Межбуквенный интервал не задаётся. Аккордеоны: шеврон вниз/вверх; нажимается вся строка. Состав — список с галочками из рабочего виджета. Кнопка с самолётиком размещена внутри поля ввода.

Прежние размеры из коммита 7c7ca52: 440 × 720 px; при высоте окна до 800 px — 420 × 680 px. Образец ограничен свободным местом под переключателем шрифтов. На телефоне занимает доступную ширину, высота ограничена тем же пределом. Это намеренно компактный образец по запросу владельца; рабочий мобильный fullscreen не меняется.

## Запуск и файлы

Локально: http://127.0.0.1:9100/ (когда запущен отдельный статический сервер). Для сервера: `python -m http.server 9100 --bind 0.0.0.0 --directory static/experiments/widget-playground`. Доступ с телефона по IP компьютера зависит от сети и её правил; переносимый HTML сети не требует. Некоторые просмотрщики вложений телефона не запускают JS — нужен браузер.

- index.html, styles.css, app.js — оболочка, навигация, подготовленный диалог.
- reference-data.js — полный снимок выбранных услуг.
- reference-renderer.js — копия форматтера/ценовой карточки и локальная версия формы.
- reference-cards.css — стили карточек и формы из рабочего виджета.
- fonts.css, assets/ — Inter, Roboto, лицензии, аватар.
- sync-reference.py — обновление снимка из локального репозитория без вызовов модели/API.
- build.py — упаковка HTML и ZIP; не обновляет Python и зависимости.

Из корня репозитория: `.venv/Scripts/python.exe static/experiments/widget-playground/sync-reference.py`, затем `.venv/Scripts/python.exe static/experiments/widget-playground/build.py`. Второй скрипт работает и без окружения бота. Результат — drafts/widget-playground/artgents-widget-playground-v2.html и artgents-widget-playground-v2.zip. В ZIP также лежат редактируемые исходники.
