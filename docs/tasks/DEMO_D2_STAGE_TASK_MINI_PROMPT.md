# D2 — короткий prompt для каждого этапа

Этот текст добавляется к карточке конкретного этапа. Карточка задаёт цель,
baseline, точный allowlist и критерии приёмки; этот prompt не заменяет
[Execution Lock](DEMO_D2_EXECUTION_LOCK.md) и
[дорожную карту](DEMO_D2_DELIVERY_ROADMAP.md).

```text
Работай только над названным этапом D2 и его точным списком файлов; сначала проверь AGENTS.md, ветку, HEAD, status и baseline.
Не меняй архитектуру, видимое поведение или порядок этапов без решения владельца; при конфликте остановись и спроси.
Обычный ответ и follow-up — живая речь модели по FullContext; проверенные коммерческие данные, политика, контакты, UI и заявки принадлежат коду.
Не добавляй смысловые regex, ветки под фразы или услуги, Composer/sales_fast, старый fallback, вторую память, prompt или parser.
Сохраняй исходный смысл вопроса при кликах, уточнениях, смене услуги и replay; не заставляй модель угадывать уже известный выбор.
Не подгоняй fake envelope и assertions: проверяй prompt, parser, HTTP/UI, сохранение и смысл ответа на разных формулировках.
Неточность живой прозы записывай локально без вырезания и блокировки; tenant, privacy, UI ownership и lead остаются строгими.
До commit покажи diff и offline-доказательства независимому Checker; live calls, merge и deploy требуют отдельного разрешения.
```
