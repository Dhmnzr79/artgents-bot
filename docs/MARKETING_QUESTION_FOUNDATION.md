# Маркетинговая карта вопросов и поведения demo-бота

**Статус:** второй компактный фундамент, 15 июля 2026 года.
**Для кого:** маркетолог, владелец — что видит и может нажать пациент.
**Не является:** текстом ответов (они в md/прайсе), техническим описанием маршрутов, гарантией widget parity.

Содержание ответа бот берёт только из согласованной базы клиники. Здесь — только **действия на экране**, не тексты отдельных ответов.

Технический слой (маршруты, модули, операции): [`MARKETING_QUESTION_TECH.md`](MARKETING_QUESTION_TECH.md).

## Продуктовые законы

1. **Бот продаёт услуги клиники.** Его целевой результат — лид: запись, заявка или прямой контакт пациента с клиникой. Бот не является самостоятельным медицинским консультантом и не ставит диагноз.
2. **Согласованная база конкретной клиники — единственный источник истины.** Бот не исправляет её по собственным знаниям и не добавляет неподтверждённые сведения.
3. **Силу утверждений менять запрещено.** Числа, проценты, гарантии, обещания, отрицания, условия и степень уверенности передаются точно. «Без боли» нельзя заменить на «почти без боли», «гарантия по договору» — на «100% гарантия», а `99,8%` — округлить или дополнить оговоркой от себя.
4. **Связующий текст допустим, изменение смысла — нет.** Бот может связно оформить ответ, но не вправе медицински, юридически или стилистически смягчать согласованную формулировку клиники.
5. **CTA работает на лид.** В подходящем ответе показывается одна основная CTA; её можно повторять в следующих уместных ответах. Лучше показать уместную CTA лишний раз, чем потерять возможность контакта.
6. **Релевантная акция показывается сразу.** Если действующая акция связана с темой вопроса, пациент видит её в первом релевантном ответе — в том числе при вопросе о страхе или противопоказаниях.
7. **Акция не повторяется в каждом сообщении.** Одна и та же акция показывается один раз за сессию. При смене темы можно показать другую релевантную акцию. Прямой вопрос об акции всегда получает ответ, даже если акция уже показывалась.
8. **Срочная боль, острое осложнение после лечения, жалоба, спор или отзыв, требующий реакции, — жёсткая зона ручного контакта.** Бот показывает только фиксированное сообщение из §10: без свободного текста, акций, CTA, кнопок, видео и рекомендаций.
9. **Вопрос об отзывах не равен жалобе.** «Где посмотреть отзывы?» — обычный вопрос доверия; негативный отзыв или претензия — ручной контакт по §10.

## Легенда: что может появиться на экране

| Элемент | Что видит пациент |
|---|---|
| Текст из материала | Ответ из md-документа по теме вопроса |
| Ценовая карточка | Название услуги, сумма, единица расчёта |
| Несколько карточек | Варианты (бренд, протокол, пакет) |
| Обзор цен | Несколько направлений без выбора одной услуги за пациента |
| CTA-кнопка | Одно основное действие: план, цена, обсудить, запись, звонок, врач |
| Follow-up кнопки | Подсказки на разделы материала («подробнее») |
| Кнопки прайса | «Что входит», «Оплата по этапам» |
| Уточнение кнопками | «О какой услуге?» — выбор варианта кнопками |
| Меню тем | Короткий набор кнопок при непонятном запросе |
| Видео | Тематический ролик под ответом |
| «Рассказать о ситуации» | Кнопка для свободного описания случая |
| Карточка врача | Имя, специализация, опыт |
| Сбор контакта | Имя → телефон → сообщение demo |
| Только телефон | Короткая фраза + номер клиники, без кнопок |
| Акция в тексте | Релевантная действующая акция в первом подходящем ответе; та же акция не повторяется в каждом сообщении |

**Ограничения виджета:** обычно одна CTA и 1–2 follow-up; видео и «Рассказать о ситуации» делят слоты. Это текущее ограничение отображения, но продуктовый приоритет — не терять уместную основную CTA.

### Частота акции и CTA

- CTA и акция — разные элементы: CTA может повторяться в следующих подходящих ответах.
- Одна и та же акция показывается один раз за сессию — в первом ответе, где она релевантна теме.
- Другая акция при смене темы может быть показана отдельно.
- Если пациент прямо спрашивает об акции, бот отвечает независимо от предыдущего показа.
- Эти правила не действуют в жёсткой зоне §10: там остаётся только фиксированный ручной контакт.

### Контекст диалога

| Код | Значение |
|---|---|
| `standalone` | Хватает одного сообщения пациента |
| `carry` | Ответ опирается на предыдущий ход (уже названа услуга, тема) |
| `clarify` | Бот переспрашивает: услуга, масштаб или этап — **не диагноз** |

| Подтип | Примеры | На экране | Запрещено |

> Чтобы вам быстрее помогли, пожалуйста, свяжитесь с администратором клиники. Если вопрос срочный, лучше сразу позвоните: **[номер клиники]**.

Номер подставляется из настроек конкретной клиники. После этого сообщения бот ничего не добавляет. Обычный вопрос «Где посмотреть отзывы?» относится к §1, а не к этой зоне.

## Правила

1. Согласованная база клиники — единственный источник содержания; изменять смысл или силу утверждения запрещено.
2. Кнопки только те, что заложены в материале, прайсе или общей продуктовой политике.
3. Одна основная CTA; follow-up — обычно 1–2 штуки. CTA может повторяться в следующих уместных ответах.
4. Релевантная акция показывается в первом подходящем ответе; одна и та же акция — один раз за сессию.
5. Запись не подтверждает дату и время.
6. §10 — только фиксированное сообщение с телефоном, ничего лишнего.
