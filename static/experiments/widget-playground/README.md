# Песочница оформления виджета Artgents

Отдельный статический макет на HTML, CSS и JavaScript. Не подключается к API бота, модели, базе диалогов или отправке заявок. Контакты остаются только в оперативной памяти страницы. В localStorage сохраняются только значения настроек оформления.

## Открыть

При работающем локальном боте: `http://127.0.0.1:9001/static/experiments/widget-playground/index.html`.

Для телефона запустите отдельный статический сервер из этой папки:

```powershell
python -m http.server 9100 --bind 0.0.0.0 --directory "C:\Cursor Projects\artgents-bot-active\static\experiments\widget-playground"
```

Телефон и компьютер должны быть в одной Wi-Fi сети. На телефоне откройте `http://IP-КОМПЬЮТЕРА:9100/`. Сервер раздаёт только эту папку; файлы бота не используются. Компьютер должен оставаться включённым. Остановка сервера в терминале — Ctrl+C.

## Что можно менять

Inter и Roboto переключаются в верхней панели без сброса открытого экрана. Кнопка «Настройки» открывает размеры основного и второстепенного текста, заголовков и цены, межстрочный интервал, поля по краям, отступы строк услуг и расстояния между блоками. Ширина на компьютере регулируется отдельно; на телефоне виджет занимает всю доступную ширину.

Настройки применяются сразу и сохраняются после обновления страницы. «Скачать настройки CSS» выгружает текущие значения CSS-переменных; «Сбросить оформление» возвращает исходные значения. Это локальные настройки песочницы, а не автоматическое изменение рабочего виджета.

В списке «Открыть пример» можно сразу перейти к диалогу, каталогу, вариантам, полной карточке с оплатой и акцией, точной цене, цене «от», диапазону, отсутствующей публичной цене, группам зон, цене за единицу, форме и успешной заявке.

Основная навигация: «Помощник / Услуги и цены / Запись». Переписка не сбрасывается при смене вкладки. Услуги открываются через направления или поиск. Несколько предложений сначала показываются списком; после выбора открывается отдельная карточка без табов. Услуга без публичной цены остаётся в списке без заменяющей цену надписи. Состав, доплаты, условия, оплата и акция раскрывают разные состояния интерфейса.

В диалоге доступны подготовленные ответы, кнопки продолжения, ценовые варианты и форма. Произвольный текст добавляется в переписку и получает подготовленный ответ. Это интерфейсная имитация, а не медицинский консультант.

Имя и телефон вводятся до галочки. Отправка без заполненных контактов или согласия показывает ошибку; успешная отправка отображает благодарность и ничего не отправляет по сети. Выбранная позиция и черновик общие для формы внутри каталога, диалога и вкладки «Запись». Для проверки используйте тестовые контакты. После обновления страницы контакты исчезают. Внешний переключатель примеров позволяет снова открыть форму или состояние успеха.

## Файлы

- `index.html` — разметка виджета и панели настроек.
- `styles.css` — существующая визуальная система и регулируемые CSS-переменные.
- `app.js` — примеры услуг, навигация, переписка, формы и настройки.
- `fonts.css` и `assets/` — локальные Inter, Roboto, лицензии и аватар.
- `build.py` — сборка переносимого HTML и ZIP без подключения к боту.

Запуск `python build.py` создаёт в `drafts/widget-playground/` два файла: `artgents-widget-playground.html` со встроенными CSS, JS, шрифтами и аватаром, и `artgents-widget-playground.zip` с этим HTML и редактируемыми исходниками. Шрифты не требуют Google Fonts или доступа в интернет. Переносимый HTML нужно открывать в браузере; встроенный просмотрщик вложений телефона может не исполнять JavaScript.
