1. Запустить бота

PowerShell

Открой PowerShell на компьютере и вставь команду. Затем открой Demo, АртМед или НикаДент по ссылкам выше.

& "C:\Cursor Projects\artgents-bot-active\scripts\start_local_widget.ps1"

Порт 9001. Окно оставь открытым. Изменения Python подхватываются автоматически.

2. Запустить админку

PowerShell

Вставь в другое окно PowerShell. Админка читает сохранённые данные и может работать без запущенного бота.

& "C:\Cursor Projects\artgents-bot-active\scripts\start_local_admin.ps1"

Порт 9100. Окно оставь открытым. После изменения Python админки — остановить и запустить снова.

3. Новая беседа в демо

В чат виджета

В Demo или АртМед вставь в поле сообщения виджета и нажми отправку. Дождись завершения текущего ответа.

::reset x7k9m2p4

Команда обрабатывается виджетом, к модели не отправляется. На локалке проще нажать «Новая беседа» в панели управления.

4. Сброс сессии через F12

Браузер · Console

Открой страницу с нужным виджетом → F12 → Console / Консоль. Выбери клиента здесь, скопируй команду туда и нажми Enter.

localStorage.removeItem("clinic_widget_sid:nikadent"); location.reload();

Выполняй на сайте с виджетом, а не на этой странице и не в админке. Локалка и сайт НикаДент имеют разные сессии. Страница перезагрузится.

Остановить: Ctrl+C в окне нужного процесса. Перезапустить: остановить и снова выполнить его команду.
Ссылки открывают страницы, а процессы запускаются командами. Сброс начинает новую беседу в этом браузере; серверную историю и лимиты он не удаляет. Если ответ ещё идёт — сначала дождись завершения.
VPS · вход и проверка — ещё 4 команды

5. Добавить SSH-ключ

PowerShell

На своём компьютере. Если ключ ещё не добавлен в SSH-agent, введи его парольную фразу по запросу. Символы при вводе скрыты.

ssh-add "$env:USERPROFILE\.ssh\artgents_timeweb_ed25519"

6. Подключиться к VPS

PowerShell

На своём компьютере. После входа появится deploy@… — это уже терминал Linux на сервере.

ssh -i "$env:USERPROFILE\.ssh\artgents_timeweb_ed25519" deploy@5.129.195.70

Вернуться в PowerShell: набрать exit и нажать Enter. Локальные команды запуска выше выполняются на компьютере.

7. Открыть серверную админку

PowerShell

На компьютере. Создаёт закрытый SSH-туннель; ничего на VPS не запускает и не обновляет. Окно оставь открытым.

& "C:\Cursor Projects\artgents-bot-active\scripts\start_vps_admin.ps1"

Затем открой админку VPS и введи свой логин и пароль админки. Это серверные данные. Адрес 9100 остаётся для локальной версии. Ctrl+C закрывает только туннель.

8. Проверить готовность VPS

PowerShell

На компьютере. После подключения введи Linux sudo-пароль пользователя deploy в терминале. Ввод скрыт; пароль в чат не отправляй.

& "C:\Cursor Projects\artgents-bot-active\scripts\audit_vps_admin.ps1"

Только чтение: версии, состояние служб, порты, подключение данных и наличие настроек. Значения паролей, хешей и ключей не выводятся. Вывод проверки можно прислать для разбора. Выкладки, перезапуска, отправки писем и вызовов модели нет.
