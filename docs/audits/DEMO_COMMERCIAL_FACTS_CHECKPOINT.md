## 2. Кандидаты без отдельного fact ID

Условия из `clinic__info__payment_terms.md#korotko`, не оформленные как fact:

| Условие | Источник | Предлагаемая формулировка (на согласование) | Границы |
|---|---|---|---|
| Оплата по этапам | payment_terms MD | «Оплата по этапам: сначала хирургия, затем ортопедический этап» | Конкретные суммы — только в offers; срок «3–4 месяца» — для классического протокола, не для всех услуг |
| Фиксированная стоимость в договоре | payment_terms MD | «Стоимость фиксируется в договоре до начала лечения» | Общее условие клиники |
| 3 варианта плана по бюджету | payment_terms MD | «На консультации предлагают несколько вариантов плана по бюджету» | Не дублировать consultation_value |
| Без скрытых доплат | payment_terms MD | «Без скрытых доплат — оплачивается то, что согласовано на консультации» | Общее условие |

**Не добавлять** в facts.json без отдельного checkpoint.
